# 📊 Sales Annual Report 2025 – Excel Dashboard

An interactive Excel dashboard created to analyze sales performance, customer demographics, order status, sales channels, and state-wise sales for 2025.

## 📌 Project Overview

This project uses Excel to transform raw sales data into an interactive dashboard that helps identify important sales and customer trends.

The dashboard provides a clear view of:
- Sales and order performance
- Customer distribution by gender
- Order status
- State-wise sales
- Age group and gender analysis
- Sales across different order channels

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning & Filtering
- Excel Dashboarding

## 📂 Dataset

The dataset contains customer and order-level information including:

- Customer ID
- Gender
- Age
- Age Group
- Date
- Month
- Order Status
- Sales Channel
- SKU
- Category
- Size
- Quantity
- Currency
- Amount
- Shipping City
- Shipping State
- Shipping Postal Code
- Shipping Country

## 🎛️ Interactive Filters

The dashboard includes interactive filters for:

- Month
- Sales Channel
- Product Category

These filters allow users to dynamically explore the sales data.

## 💡 Key Insights

- Compared sales amount with order volume.
- Analyzed customer distribution by gender.
- Evaluated delivered, returned, and cancelled orders.
- Identified states with higher sales.
- Compared purchasing patterns across different age groups and genders.
- Analyzed order channels and product categories.
